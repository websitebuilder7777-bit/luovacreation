How to get a GitHub Access Token in 30 seconds:

  1. Log into your account on GitHub.com.
  2. Click your profile picture (top-right) → Settings.
  3. In the left sidebar, scroll down to the bottom and click Developer Settings.
  4. Click Personal access tokens → Tokens (classic) → Generate new token (classic).
  5. Give it any note (e.g., "Luova Admin"), set expiration, and check the repo scope checkbox.
  6. Click Generate token, copy the code, and paste it into the box above!
